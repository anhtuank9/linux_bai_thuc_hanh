# Bài thực hành Linux

## 1. Giới thiệu

Bài thực hành sử dụng Ubuntu/Linux để:

- Tạo cây thư mục.
- Tạo và xử lý file CSV.
- Viết Shell Script tính tổng doanh thu.
- Viết Python Script đếm số từ trong chuỗi.
- Push project lên GitHub.
